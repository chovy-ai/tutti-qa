## 2. 本批定下的口径

| 问题 | 答复 |
|---|---|
| 共享 Agent 的来源 | 使用者 B 的下拉列出所有者 A 的五类来源，用量全部计入 A；B 看不到 A 的账号邮箱与 Key，不能管理；多账号按 A 的首选顺序换号 |
| 额度保护 | 只管该 Agent 自己的官方账号（含多账号），其他 Agent 订阅不受额度保护 |
| /status | 官方账号、官方多账号显示会话、上下文与模型；其他 Agent 订阅、Tutti API、API Key 只显示会话 ID 与上下文，不显示模型 |
| 云端首次使用 | 云端房间里直接在 Agent 选择的「我的 Agent」页签选云端 Agent 发送，不用先去管理页；首次发送有准备中状态、可停止，准备完成后回复，默认 Tutti API；准备界面在改版，只断言行为不断言文案 |
| 模型失效、续聊 | 沿用参考分组的已定口径 |
