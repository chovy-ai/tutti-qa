## 5. 关键断言与本轮定稿口径

| 口径 | 结论 | 依据 |
|---|---|---|
| 落点 | 新建「Computer 与 Agent 管理 / 云端电脑」 | QA 确认 |
| 默认可用 | 设置完成后，Claude Code / Codex 默认用内置的 Tutti 积分，显示「可用 · 1 个模型来源」 | 需求文档 |
| 本地与云端 | 本地已登录不代表云端已登录，云端要单独登录 | 需求文档 |
| 模型来源 | 官方订阅、Tutti 积分、API Key 三种；配了几种就显示「N 个模型来源」 | 需求文档 |
| 官方订阅以 API Key 方式配置 | 是其中一种模型来源：卡片显示 API Key 配置、不显示「登录」；定为 **P0** | 需求文档、QA 确认 |
| 官方订阅登录 | Claude Code 粘贴授权码，Codex 输入设备码；登录中可以取消；用量拿不到时不显示 | 需求文档、代码 |
| API Key 同步 | 同协议的 Agent 在本地电脑与云端电脑之间互相同步，同步过去的默认不开启 | 需求文档 |
| Tutti 积分跳转 | 「升级会员」跳 `https://tutti.sh/profile/plan`；余额旁的「>」跳 `https://tutti.sh/profile/usage` | 需求文档 |
| 移除 Agent | 提示「移除 <Agent>? 会话会保留」，移除后显示「安装」 | 需求文档 |
| 重启、升级中断 | 运行中的任务收敛为已中断，不自动续跑，可在原会话继续；排队消息保留 | QA 确认、代码 |
| 删除云端电脑 | 历史会话只能看，不能继续；重新创建也接不上旧会话 | QA 确认 |
| 共享 | 可以共享给房间，名称为「<主人> 的云端 <Agent>」，用量记在主人名下；只有主人能管理云端电脑 | QA 确认、代码 |
| 本地 skill / 插件 | 不同步到云端 | 需求文档答复 |
| 房间规格 | 轻享型（2 核 4GB，默认）或性能型（4 核 8GB），只能在创建时选；「允许 root」默认勾选 | QA 确认、代码 |
| 空闲暂停 | 显示「在线」，有任务时自动恢复 | 代码 |

**出稿假设**（QA 没有回答对应问题，我按推荐口径写的）：

- 云端 Agent 的会话能力与本地一致，包括斜杠命令、MCP、Skill、子 Agent、图片、AskUserQuestion、上下文用量、使用概览、Handoff、Fork。
- 云端不提供 /computer use 与 /browser。
- 不写多房间并发上限。

**容易漏掉或写反的断言**：

- **反向断言**：本地房间不出现云端电脑或云端 Agent；云端不同步本地配置；云端不提供 /computer use 与 /browser。
- **身份分离**：只有主人能管理云端电脑，成员看不到主人的凭据；未共享时，成员不能借主人的会话驱动主人的云端 Agent。
- **变体对照**：
  - Claude Code 与 Codex 的官方订阅登录逐项对照。
  - 云端与本地 Agent 的会话能力逐项对照（主干是「Tutti API 与自定义模型 / 会话执行 · 自己的 Agent」）。
