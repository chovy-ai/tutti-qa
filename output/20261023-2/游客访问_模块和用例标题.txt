房间管理 · 游客配置
    游客模式与讨论权限
        开启游客模式、复制链接并完成首位游客准入 · 全链路
        切换讨论开关并校验群聊和评论的完整权限链
        讨论选择跨游客模式关闭和重开保持且不覆盖其他权限
        关闭游客模式、保留历史并经房主恢复访问 · 全链路
        非房主无权查看或修改游客管理配置
        保存被拒绝后保持原配置并可重新提交
        保存成功但读回失败时禁止继续写与复制旧链接
        并发修改遇到旧版本时读回最新状态后再确认
        模板限制讨论权限时保持禁用并在权限恢复后可操作
        权限目录不可用时阻止启用并在目录恢复后完成准入
        提交期间重复点击只产生一次有效变更
        关闭面板后的迟到响应不污染重开或其他房间
    游客邀请链接
        暂停、刷新再启用保留同一邀请且区分已加入身份
        更换链接后旧链接不可加入且已有游客保留
        在会话中复制邀请只保留目标会话定位
        已有历史配置初次补齐邀请后立即可复制且版本一致
        复制失败保留真实链接并在恢复后成功复制
    入口边界与能力说明
        游客权限说明与实际讨论、读取和执行能力一致
        公开房间不提供私人游客配置且普通房间入口不被污染
房间管理 · 成员与游客
    人员列表与身份变更
        人员展示、角色状态筛选与分页完成完整核对
        游客升级成员后校验席位、会话执行与刷新 · 全链路
        成员降为游客后保留运行任务与历史并撤销共享 · 全链路
        移出游客后保留历史并由房主恢复为游客
        恢复已移出成员时重新检查名额并恢复正确身份
        游客主动退出后关闭访问并保留历史
        游客不能用成员邀请绕过房主自行升级
        成员名额已满时升级失败后腾出名额再成功
        人员版本冲突不把已移出的人错误升级
        身份修改失败后保留菜单上下文并可重试
        游客分页加载失败保留已有人员并可继续正确加载
        游客超过成员限额仍可加入且升成员才检查席位
        重复确认角色变更不重复占用席位
    头像与本人管理边界
        未分组游客显示真实头像且加载失败正常回退
房间 · 登录游客
    侧栏入口与房间身份
        登录账号通过游客邀请入房并在侧栏持续访问 · 全链路
        现有成员打开游客链接保持成员身份
        同账号在成员房间与游客房间间切换不串权限
        重复打开有效邀请不生成重复游客关系
    默认会话、公告与正文浏览
        共享会话、公告与持续更新的只读浏览 · 全链路
        复制正文与引用只操作本地剪贴板
        会话或公告读取失败后重试仍恢复原目标
        长会话分页与中途新回复不重复不串会话
    交付文件与房间资产
        交付卡片到多入口预览、下载和内容核对 · 全链路
        不支持预览的格式仍能完整取得原文件
        文件中心筛选、分页与详情只读取房间授权资源
        相对图片和附件从同一授权文档正确加载
        文件预览失败后恢复同一文件且不影响会话
        禁用资产读取后多个入口一致拒绝且恢复授权可读
        跨房间和私有文件替换不能读取且合法文件仍可用
        空资产和删除后的资源不展示成其他房间内容
    网站与外链浏览
        从交付网站到原域名、深路径与相对资源只读浏览 · 全链路
        普通外链在新页打开并保留业务参数
        网站未运行时明确不可用且成员启动后可恢复浏览
        站点无权或预览失败不被启动操作掩盖
    群聊
        群聊发送、提及成员、编辑删除本人消息与多端同步 · 全链路
        讨论关闭后的历史可读与重新开启后发送
        群聊提及 Agent 只作为讨论且不触发执行
        群聊发送明确失败后回滚临时态再成功发送
        群聊分页期间新消息不被旧响应覆盖
    全局评论与划线评论
        全局评论、回复提及与角标持久化 · 全链路
        划线评论从选区到定位、编辑与删除完整闭环
        评论讨论关闭时保留原文和历史且重新授权可恢复
        评论包含 Agent 提及也不改变执行状态
        评论发送失败后恢复列表和角标并重试成功
        不能编辑删除他人消息评论且本人内容仍可管理
    Agent 输入、新建与执行控制
        新建和派生会话均受限且不残留空会话
        已有会话不能追问执行或篡改请求启动 Agent
        游客不能审批或回答 Agent 的执行交互
        游客不能暂停取消运行且不会中断成员任务
    任务与自动化只读
        任务列表到详情、动态、交付和关联会话只读闭环
        自动化列表、配置和运行记录只读链路
        任务写入与执行请求被拒绝后成员仍可正常流转
        任务读权限缺失时不展示缓存且授予后恢复
        自动化写入与执行不能借只读权限绕过
        自动化空态、读取失败和权限关闭区分处理
    共享 Agent 与房间内容管理
        共享 Agent 目录与详情可读但不可请求共享或调用
        共享目录权限关闭或关系撤销后不能沿用旧列表
        游客不能上传编辑删除成果或创建分享权限
        游客不能改公告房间配置或邀请提权
    撤销、旧标签与跨房间隔离
        移出后旧标签停止读取新内容且恢复后只读重建
        成员降级后旧执行页不能继续沿用成员权限
        会话参数跨房间替换被拒绝后仍可浏览合法会话
房间 · 匿名访问
    侧栏入口、主动登录与身份隔离
        匿名准入与主动登录后的游客关系建立 · 全链路
        鼠标触屏键盘访问禁用原因且不触发登录或原操作
        匿名分享不授予账号级页面和私人资源权限
        多房间匿名凭证共存不串房间且账号身份优先
    会话、讨论与资源浏览差异
        匿名浏览消息、评论和群聊但不产生写入或成员已读
        匿名读取环境变量只显示名称且无敏感值
        匿名文件预览与下载只使用本房间资源授权
        匿名网站原域名及深路径读取不会泄露凭证到站点
        匿名读取缺失能力不借可写提示或其他权限放行
    临时凭证、撤销与恢复
        固定七天凭证在期限内浏览不续期且到点终止
        临时凭证到期在后台恢复时先校验再显示内容
        暂停链接或关闭模式后匿名授权被撤销并停止新读取
        准入临时故障重试恢复同一房间且不无限续期
        退出登录清理新旧匿名凭证且迟到旧续期不能复活
        多标签更新凭证后旧页恢复采用当前凭证而非误判到期
        系统时钟变化不改变服务端固定截止时间
        旧滑动凭证与新固定凭证按返回模式分别处理
    身份能力逐项对照
        登录游客与匿名访客的能力范围逐项对照
