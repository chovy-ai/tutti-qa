## 5. 关键断言

- **链尾三件事**：房间执行的每条用例都断言模型不被悄悄换成其他来源、用量计入正确的来源、网关最近请求能对上本会话的 Session 与 Turn。
- **反向断言**：来源失效、所有账号用完、积分为 0 时，不自动改用 Tutti API 或其他付费来源。
- **不拼接**：多账号与路由组中，已经在输出的请求断了就报错，不出现两个账号拼起来的回答。
- **首选规则**：上移、下移、设为首选、移除首选后，新会话都由新的第一个账号承接；第一个账号不能上移、最后一个不能下移。
- **@ 智能体**：被 @ 的 Agent 用它自己当前选的模型与来源，用量计入它自己的来源（沿用宿主库「会话执行 · 自己的 Agent」的已定口径）。
- **运行位置隔离**：三个运行位置的来源配置互相独立；云端房间读不到其他电脑的订阅与 Key；隔离虚拟机与当前电脑不同步登录态。
